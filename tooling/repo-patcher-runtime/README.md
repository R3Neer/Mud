# Snapshot de repo-patcher

Esta carpeta contiene una copia del código Python y de los metadatos de la
versión de repo-patcher instalada mediante pipx.

Se conserva para poder reproducir y probar localmente los paquetes de cambios
antes de entregarlos.

No se incluyen:

- el ejecutable lanzador específico de Windows;
- __pycache__;
- archivos .pyc o .pyo.

El entorno exacto está documentado en ENVIRONMENT.txt y
equirements-installed.txt.
