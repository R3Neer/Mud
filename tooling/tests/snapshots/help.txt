SNAPSHOT decisions

====================================================================
 MUD DECISIONS
====================================================================
Manage Mud architecture decision records and their generated index.

USAGE
  python tooling/decisions/manage_decisions.py <command> [--colour MODE] [--ascii]
  python tooling/decisions/manage_decisions.py <command> --help

GLOBAL OPTIONS
  --colour auto|always|never  Control colour for human output. Default: auto; NO_COLOR disables it.
  --ascii                     Use ASCII status symbols when Unicode is unsuitable.

DECISIONS
  migrate   Migrate legacy ADR metadata
  generate  Generate the decision index
  validate  Validate decisions and relationships

* Run python tooling/decisions/manage_decisions.py <command> --help for detailed help.

SNAPSHOT questions

====================================================================
 MUD QUESTIONS
====================================================================
Generate or validate Mud's active-question index.

USAGE
  python tooling/questions/validate_questions.py [validate|generate] [--colour MODE] [--ascii]
  python tooling/questions/validate_questions.py <command> --help

GLOBAL OPTIONS
  --colour auto|always|never  Control colour for human output. Default: auto; NO_COLOR disables it.
  --ascii                     Use ASCII status symbols when Unicode is unsuitable.

QUESTIONS
  validate  Validate questions and the index
  generate  Generate the active-question index

* Running without a command performs validation.
