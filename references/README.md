# References

This folder contains reports and supporting materials which **are not part of the specification regulations**.

## Rule of authority

For reference:

- It is not used directly for implementation.
- It does not introduce any rules of language.
- It does not turn a statement into current for describing it.
- You must cite the legal sources or decisions on which you are relying.

The authority current is query in this order:

1. [[specification/README|Specification formally]].
2. [[notes/decisions/README|Decisions currently in force]] and its ADRs.
3. [[notes/questions/README|Active questions]].

The snapshots and audits that have been removed are stored in the Git history. Evidence of the end of their migration is recorded in [[notes/questions/Q-010-estado-de-las-decisiones-de-la-fuente|Q-010]].
