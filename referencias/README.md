# Referencias históricas

Esta carpeta conserva fuentes de ideación, instantáneas y documentos de procedencia que resultan útiles para reconstruir la evolución de MUD, pero que **no forman parte de la especificación normativa**.

## Regla de autoridad

Una referencia histórica:

- Puede mostrar requisitos ya sustituidos o retirados.
- Puede contradecir decisiones posteriores.
- No se usa directamente para implementar.
- No convierte una afirmación en vigente por describirla como tal.
- Debe consultarse junto con su auditoría y los avisos de obsolescencia.

La autoridad actual se consulta en este orden:

1. [[especificacion/README|Especificación formal]].
2. [[notas/10-registro-de-decisiones|Registro de decisiones]] y ADR vigentes.
3. [[notas/08-preguntas-abiertas|Preguntas abiertas]].
4. Referencias históricas, solo para procedencia.
