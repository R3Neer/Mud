# Preguntas activas de MUD

Este índice contiene únicamente preguntas en estado `abierta` o `parcialmente-decidida`. Su gestión se rige por [[gobierno/POLITICA-DE-PREGUNTAS|Política de preguntas de MUD]].

La migración desde [[notas/08-preguntas-abiertas|el registro anterior]] es incremental. Hasta completarla, las preguntas todavía no separadas se consultan allí. Las preguntas nuevas y las preguntas que vuelvan a modificarse usan un archivo propio en esta carpeta.

## Preguntas separadas activas

Actualmente no hay preguntas activas ya separadas del registro anterior.

## Preguntas cerradas separadas

Las preguntas cerradas no forman parte de este índice activo. Sus archivos estables se conservan para resolver enlaces históricos; por ejemplo, [[Q-055-literales-de-magnitudes-de-punto|Q-055]].
